## ✨ Overview

This project uses **Terraform** to deploy:

- 🎛️ **Control-plane** Auto Scaling Group (`t3.micro`)
- ⚙️ **Worker** Auto Scaling Group (`t3.micro`)
- 🔐 A generated RSA **key pair** (`ec2-key`)
- 🌐 A VPC with private subnets and an SSH security group

---

## 🚀 Getting Started

```bash
cd infra

# 1️⃣ Initialize Terraform
terraform init

# 2️⃣ Preview the changes
terraform plan

# 3️⃣ Apply the infrastructure
terraform apply -auto-approve
```

## 🔑 Retrieve Your Key Pair

The private key is generated by Terraform and stored as a sensitive output. Save it to a local `.pem` file:

```bash
terraform output -raw key_pair_private_key > ec2_key.pem

# 🔒 Fix permissions (required by SSH)
chmod 400 ec2_key.pem
```

## 🖥️ Create a Temporary Bastion Host

Since the instances live in **private subnets**, use a temporary **bastion host** in a public subnet to reach them.

```bash
# 1️⃣ Create a temporary security group allowing SSH (22) from your IP
aws ec2 create-security-group \
  --group-name bastion-sg \
  --description "Temporary bastion host security group" \
  --vpc-id <VPC_ID>

# 2️⃣ Allow inbound SSH from your IP
aws ec2 authorize-security-group-ingress \
  --group-id <SECURITY_GROUP_ID> \
  --protocol tcp \
  --port 22 \
  --cidr <YOUR_IP>/32

# 3️⃣ Launch a temporary bastion instance (Amazon Linux 2)
aws ec2 run-instances \
  --image-id ami-0c55b159cbfafe1f0 \
  --instance-type t2.micro \
  --key-name ec2-key \
  --security-group-ids <SECURITY_GROUP_ID> \
  --subnet-id <PUBLIC_SUBNET_ID> \
  --associate-public-ip-address \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=temp-bastion}]'

# 4️⃣ Get the bastion's public IP
aws ec2 describe-instances \
  --filters "Name=tag:Name,Values=temp-bastion" \
  --query "Reservations[].Instances[].PublicIpAddress" \
  --output text
```

## 🔌 Connect via SSH

```bash
# 🖥️ SSH into the bastion host
ssh -i ec2_key.pem ec2-user@<BASTION_PUBLIC_IP>

# 🔁 From the bastion, hop into a private instance
ssh -i ec2_key.pem ec2-user@<PRIVATE_INSTANCE_IP>
```

---

## 📤 Copy the PEM Key with SCP

Copy the key (or any file) from your local machine to the bastion host:

```bash
# 📤 Upload the PEM key to the bastion
scp -i ec2_key.pem ec2_key.pem ec2-user@<BASTION_PUBLIC_IP>:~/

# 🔒 Fix permissions on the bastion
ssh -i ec2_key.pem ec2-user@<BASTION_PUBLIC_IP> "chmod 400 ~/ec2_key.pem"

# ⬇️ Download a file from the bastion to your local machine
scp -i ec2_key.pem ec2-user@<BASTION_PUBLIC_IP>:~/remote_file.txt .
```

## 🧹 Cleanup

```bash
# 🗑️ Terminate the temporary bastion host
aws ec2 terminate-instances --instance-ids <INSTANCE_ID>

# 🗑️ Delete the temporary security group
aws ec2 delete-security-group --group-id <SECURITY_GROUP_ID>

# 🧹 Destroy all Terraform-managed infrastructure
cd infra
terraform destroy -auto-approve
```
